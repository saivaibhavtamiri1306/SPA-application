# 60-second interview explanation

"TrustVault Core is a background-verification operations console. I used Angular 18 because the requirement was Angular 12+, and I built the application around feature-level routing, services, guards and an HTTP interceptor. Authentication is split into login, a short-lived MFA step and an access JWT. The backend is Node.js + Express + TypeScript, with role enforcement on API mutations and a persistent XML store because XML was one of the challenge-approved storage options. I added a configurable `delay` query parameter to demonstrate asynchronous UI states, and the dashboard loads multiple API resources concurrently. The audit ledger uses a virtual rendering strategy and a Web Worker for SHA-256 chain verification so heavy work does not freeze the UI. The original cyber-security visual language was preserved and expanded with responsive glassmorphism, 3D Three.js effects, animated scan states, masking and export actions."
